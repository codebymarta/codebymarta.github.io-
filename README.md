
#  GlowLog: Tu Asistente Personal de Skincare & Rutinas
 
 >*"Cuidar tu piel es un proceso diario, no un milagro de una noche."*

## ¿En que consiste GlowLog?
**GlowLog** es una aplicación web pensada para organizar de forma sencilla y visual todo lo relacionado con el cuidado facial.

Permite crear rutinas personalizadas de mañana y noche, gestionar un neceser virtual con los cosméticos que tienes en casa y los nuevos, y detectar posibles incompatibilidades entre ingredientes activos para evitar irritaciones.


## Pantallas que deberia tener la aplicacion
*Pantalla inicial:*
   - Rutina de mañana y noche
   - Lista con checks
   - Recordatorios 

*Mi Neceser Virtual:*
   - Catálogo visual en tarjetas con todos mis productos: foto, marca, tipo 
   - Semáforo de caducidad (verde: reciente; amarillo: próximo a vencer; rojo: caducado)
   
*Creador Virtual de rutina:*
   - Diseñador visual paso a paso para ordenar la   aplicación: Limpieza,Tónico,Tratamiento Hidratación
   - Alertas automáticas si intentas combinar ingredientes no compatibles.
